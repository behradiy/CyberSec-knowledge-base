# What Happened in Cybersecurity: July 2024 – November 2026

This repository went quiet in July 2024. This timeline catches up on everything important that happened since then, month by month. Each line links to a primary source (or the best available report) so you can dig deeper. Topics are tagged:

* 🍯 Honeypots & deception
* 🛡️ Detection, IDS & SOC
* 🐞 AI finding and fixing vulnerabilities
* 🦹 Attackers using AI
* 🤖 Securing AI systems
* 🔐 Cryptography & post-quantum
* 🌍 Major incidents & policy

Detailed explanations live in the folders: [Honeypots](Honeypots/), [IDS](IDS/), [AI-Attack-and-Defense](AI-Attack-and-Defense/), [Securing-AI](Securing-AI/) and [Papers](Papers/).

## 2024

**July**
* 🌍 **Jul 19:** A faulty CrowdStrike Falcon update crashes about 8.5 million Windows machines worldwide, showing that kernel-level security agents are a systemic risk. [Microsoft](https://blogs.microsoft.com/blog/2024/07/20/helping-our-customers-through-the-crowdstrike-outage/)

**August**
* 🔐 **Aug 13:** NIST publishes the first post-quantum standards: FIPS 203 (ML-KEM), FIPS 204 (ML-DSA) and FIPS 205 (SLH-DSA). [NIST](https://csrc.nist.gov/Projects/post-quantum-cryptography/news)

**October**
* 🍯 **Oct 17:** Palisade Research launches the LLM Agent Honeypot to catch AI hacking agents in the wild. [arXiv](https://arxiv.org/abs/2410.13919)
* 🌍 **Oct 25:** The FBI and CISA confirm Chinese "Salt Typhoon" intrusions into US telecom carriers, later shown to target lawful-intercept systems. [CISA](https://www.cisa.gov/news-events/news/joint-statement-fbi-and-cisa-peoples-republic-china-prc-targeting-commercial-telecommunications)
* 🍯 **Oct 28:** Mantis shows that prompt injection can be used *defensively* against AI attackers. [arXiv](https://arxiv.org/abs/2410.20911)

**November**
* 🐞 **Nov 1:** Google's Big Sleep agent finds an exploitable bug in SQLite, the first public case of an AI agent finding such a bug in widely used software. [Project Zero](https://projectzero.google/2024/10/from-naptime-to-big-sleep.html)
* 🤖 **Nov 17:** OWASP releases the Top 10 for LLM Applications 2025. [OWASP](https://genai.owasp.org/2024/11/17/owasp-reveals-2025-top-10-risks-for-llms-new-sponsorship-program/)
* 🛡️ **Nov 19:** Microsoft announces the Windows Resiliency Initiative, including plans to let security vendors run outside the kernel. [Help Net Security](https://www.helpnetsecurity.com/2024/11/19/windows-kernel-security-vendors/)
* 🐞 **Nov 20:** Google's OSS-Fuzz reports 26 vulnerabilities found with AI-written fuzz targets, including OpenSSL CVE-2024-9143. [Google Security Blog](https://security.googleblog.com/2024/11/leveling-up-fuzzing-finding-more.html)
* 🦹 **Nov 30:** A study shows fully AI-generated spear-phishing emails get the same 54% click rate as those written by human experts. [arXiv](https://arxiv.org/abs/2412.00586)

**December**
* 🍯 **Dec 11:** T-Pot 24.04.1 ships its first LLM-powered honeypots (Beelzebub and Galah). [GitHub](https://github.com/telekom-security/tpotce/releases/tag/24.04.1)

## 2025

**January**
* 🦹 **Jan 30:** Google reports state hackers from 20+ countries using Gemini, mostly for productivity, with no new capabilities observed. [Google GTIG](https://cloud.google.com/blog/topics/threat-intelligence/adversarial-misuse-generative-ai)

**February**
* 🍯 **Feb 5:** Splunk releases DECEIVE, an LLM honeypot that simulates a whole SSH server from one prompt. [Splunk](https://www.splunk.com/en_us/blog/security/deceive-ai-honeypot-concept.html)
* 🌍 **Feb 21:** About $1.5 billion is stolen from the Bybit exchange; the FBI attributes it to North Korea. [FBI](https://www.ic3.gov/PSA/2025/PSA250226)

**March**
* 🔐 **Mar 11:** NIST selects HQC as a backup post-quantum key-encapsulation algorithm. [NIST](https://csrc.nist.gov/Projects/post-quantum-cryptography/news)
* 🍯 **Mar 19:** Cloudflare launches AI Labyrinth, a maze of AI-generated decoy pages for misbehaving crawlers. [Cloudflare](https://blog.cloudflare.com/ai-labyrinth/)
* 🤖 **Mar 24:** Google DeepMind publishes CaMeL, a "secure by design" defense against prompt injection. [arXiv](https://arxiv.org/abs/2503.18813)
* 🤖 **Mar 24:** NIST finalizes its adversarial machine learning taxonomy, AI 100-2 E2025. [NIST](https://csrc.nist.gov/pubs/ai/100/2/e2025/final)
* 🛡️ **Mar 24:** Microsoft launches Security Copilot agents for phishing triage and more. [Microsoft](https://www.microsoft.com/en-us/security/blog/2025/03/24/microsoft-unveils-microsoft-security-copilot-agents-and-new-protections-for-ai/)
* 🛡️ **Mar 25:** An IEEE S&P 2025 SoK shows popular "encrypted traffic" datasets are mostly unencrypted. [arXiv](https://arxiv.org/abs/2503.20093)

**April**
* 🤖 **Apr 1:** Invariant Labs demonstrates MCP "tool poisoning" against AI agents. [Invariant Labs](https://invariantlabs.ai/blog/mcp-security-notification)
* 🛡️ **Apr 4:** Google announces Sec-Gemini v1, an experimental security model. [Google](https://blog.google/security/google-launches-sec-gemini-v1-new/)
* 🔐 **Apr 9:** OpenSSH 10.0 makes hybrid post-quantum key exchange (mlkem768x25519) the default. [OpenSSH](https://www.openssh.org/txt/release-10.0)
* 🌍 **Apr 15–16:** MITRE's CVE program contract nearly lapses before CISA extends it at the last minute. [The Register](https://www.theregister.com/2025/04/16/cve_program_funding_save/)

**May**
* 🌍 **May 1:** New Microsoft consumer accounts become passwordless by default (passkeys). [Microsoft](https://www.microsoft.com/en-us/security/blog/2025/05/01/pushing-passkeys-forward-microsofts-latest-updates-for-simpler-safer-sign-ins/)
* 🌍 **May 13:** The EU's own vulnerability database (EUVD) goes live at ENISA. [ENISA](https://www.enisa.europa.eu/news/consult-the-european-vulnerability-database-to-enhance-your-digital-security)
* 🦹 **May 15:** The FBI warns of AI voice clones impersonating senior US officials. [FBI](https://www.ic3.gov/PSA/2025/PSA250515)
* 🔐 **May 21:** Gidney estimates RSA-2048 could be broken with under a million noisy qubits in under a week. [arXiv](https://arxiv.org/abs/2505.15917)
* 🐞 **May 22:** Sean Heelan uses OpenAI's o3 to find a Linux kernel zero-day (CVE-2025-37899). [Blog](https://sean.heelan.io/2025/05/22/how-i-used-o3-to-find-cve-2025-37899-a-remote-zeroday-vulnerability-in-the-linux-kernels-smb-implementation/)
* 🤖 **May 26:** A malicious GitHub issue hijacks an AI agent through the GitHub MCP server to leak private repositories. [Invariant Labs](https://invariantlabs.ai/blog/mcp-github-vulnerability)

**June**
* 🤖 **Jun 11:** EchoLeak (CVE-2025-32711): zero-click prompt injection data theft in Microsoft 365 Copilot. [NVD](https://nvd.nist.gov/vuln/detail/CVE-2025-32711)
* 🤖 **Jun 16:** Simon Willison names the "lethal trifecta" for AI agents. [Blog](https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/)
* 🌍 **Jun 17–18:** Predatory Sparrow attacks Iran's Nobitex exchange, burning over $90M in crypto, and claims an attack on Bank Sepah. [Elliptic](https://www.elliptic.co/insights/iranian-crypto-exchange-nobitex-hacked-pro-israel-group/)
* 🤖 **Jun 18:** The MCP specification adds OAuth-based authorization hardening. [MCP](https://modelcontextprotocol.io/specification/2025-06-18/changelog)
* 🐞 **Jun 24:** XBOW, an autonomous pentesting system, reaches #1 on HackerOne's US leaderboard. [XBOW](https://xbow.com/blog/top-1-how-xbow-did-it/)

**July**
* 🍯 **Jul 1:** Beelzebub adds an MCP honeypot to detect hijacked AI agents. [Beelzebub](https://beelzebub.ai/blog/securing-ai-agents-with-honeypots)
* 🛡️ **Jul 8:** Suricata 8.0 is released (firewall mode, Rust HTTP parser, new protocol parsers). [Suricata](https://forum.suricata.io/t/suricata-8-0-0-released/5854)
* 🐞 **Jul 15:** Google says Big Sleep found SQLite CVE-2025-6965 before attackers could exploit it. [Google](https://blog.google/technology/safety-security/cybersecurity-updates-summer-2025/)
* 🦹 **Jul 17:** CERT-UA reports LAMEHUG, malware that asks an LLM which commands to run, attributed to APT28. [CERT-UA](https://cert.gov.ua/article/6284730)
* 🌍 **Jul 22:** Microsoft details the "ToolShell" SharePoint zero-days exploited by Chinese groups. [Microsoft](https://www.microsoft.com/en-us/security/blog/2025/07/22/disrupting-active-exploitation-of-on-premises-sharepoint-vulnerabilities/)
* 🛡️ **Jul 22:** "The Sweet Danger of Sugar" (SIGCOMM 2025) debunks traffic foundation models' near-perfect accuracy. [arXiv](https://arxiv.org/abs/2507.16438)

**August**
* 🤖 **Aug 2:** EU AI Act obligations for general-purpose AI models begin to apply. [European Commission](https://digital-strategy.ec.europa.eu/en/policies/gpai-code-practice)
* 🍯 **August:** "Cloak, Honey, Trap" is presented at USENIX Security 2025. [USENIX](https://www.usenix.org/conference/usenixsecurity25/presentation/ayzenshteyn)
* 🐞 **Aug 8:** DARPA AI Cyber Challenge final: Team Atlanta wins $4M; all finalist systems are open-sourced. [DARPA](https://darpa.mil/news/2025/aixcc-results)
* 🌍 **Aug 8–18:** Stolen Salesloft Drift OAuth tokens are used to bulk-export data from many Salesforce customers. [Google Threat Intelligence](https://cloud.google.com/blog/topics/threat-intelligence/data-theft-salesforce-instances-via-salesloft-drift)
* 🛡️ **Aug 18:** Zeek 8.0 LTS is released. [Zeek](https://community.zeek.org/t/zeek-feature-release-8-0-0/7860)
* 🦹 **Aug 26–27:** The s1ngularity attack on the Nx build tool turns developers' own AI coding assistants into secret-stealing tools. [Nx advisory](https://github.com/nrwl/nx/security/advisories/GHSA-cxm3-wv7p-598c)
* 🦹 **Aug 27:** Anthropic reports a criminal using its coding agent to automate data-extortion attacks on 17+ organizations. [Anthropic](https://www.anthropic.com/news/detecting-countering-misuse-aug-2025)
* 🌍 **Aug 27:** 23 agencies publish a joint advisory on Salt Typhoon. [CISA](https://www.cisa.gov/news-events/cybersecurity-advisories/aa25-239a)
* 🦹 **Aug 28:** "PromptLock", hyped as the first AI ransomware, turns out to be an NYU research prototype. [arXiv](https://arxiv.org/abs/2508.20444)

**September**
* 🌍 **Early Sep:** A cyberattack halts Jaguar Land Rover production for over a month; the UK Cyber Monitoring Centre estimates about £1.9bn in damage. [Infosecurity Magazine](https://www.infosecurity-magazine.com/news/jlr-hack-uk-costliest-ever-19bn/)
* 🌍 **Sep 23:** CISA warns about the Shai-Hulud self-replicating npm worm (500+ packages). [CISA](https://www.cisa.gov/news-events/alerts/2025/09/23/widespread-supply-chain-compromise-impacting-npm-ecosystem)
* 🛡️ **Sep 24:** Meta and CrowdStrike release CyberSOCEval, a benchmark for AI in the SOC. [arXiv](https://arxiv.org/abs/2509.20166)
* 🦹 **Sep 24:** Microsoft detects a phishing campaign using LLM-generated obfuscated code. [Microsoft](https://www.microsoft.com/en-us/security/blog/2025/09/24/ai-vs-ai-detecting-an-ai-obfuscated-phishing-campaign/)
* 🤖 **Late Sep:** `postmark-mcp`, the first known malicious MCP server, is caught secretly copying users' emails. [The Register](https://www.theregister.com/2025/09/29/postmark_mcp_server_code_hijacked/)

**October**
* 🌍 **Oct 4:** Oracle warns of CVE-2025-61882 in E-Business Suite, exploited in a Cl0p data-theft and extortion campaign. [Help Net Security](https://www.helpnetsecurity.com/2025/10/06/cl0p-oracle-data-theft-extortion-cve-2025-61882/)
* 🐞 **Oct 6:** Google DeepMind introduces CodeMender, an agent that fixes vulnerabilities (72 upstream fixes). [DeepMind](https://deepmind.google/discover/blog/introducing-codemender-an-ai-agent-for-code-security/)
* 🤖 **Oct 8:** About 250 poisoned documents are shown to be enough to backdoor LLMs of any size tested. [arXiv](https://arxiv.org/abs/2510.07192)
* 🍯 **Oct 8:** VelLMes, a multi-protocol LLM honeypot, is published. [arXiv](https://arxiv.org/abs/2510.06975)
* 🤖 **Oct 10:** "The Attacker Moves Second" breaks 12 published prompt-injection and jailbreak defenses. [arXiv](https://arxiv.org/abs/2510.09023)
* 🌍 **Oct 15:** CISA issues an emergency directive after a nation-state breach of F5's BIG-IP engineering systems. [CISA](https://www.cisa.gov/news-events/news/cisa-issues-emergency-directive-address-critical-vulnerabilities-f5-devices)
* 🍯 **Oct 29:** "SoK: Honeypots & LLMs" maps the whole LLM-honeypot field. [arXiv](https://arxiv.org/abs/2510.25939)
* 🐞 **Oct 30:** OpenAI announces Aardvark, an agentic security researcher (later Codex Security). [OpenAI](https://openai.com/index/introducing-aardvark/)
* 🤖 **Oct 31:** Meta publishes the "Agents Rule of Two". [Meta](https://ai.meta.com/blog/practical-ai-agent-security/)

**November**
* 🦹 **Nov 6:** Google publishes a tracker of malware that queries LLMs at runtime (PROMPTSTEAL, QUIETVAULT, PROMPTFLUX...). [Google GTIG](https://cloud.google.com/blog/topics/threat-intelligence/threat-actor-usage-of-ai-tools)
* 🦹 **Nov 13:** Anthropic reports the first AI-orchestrated cyber-espionage campaign, attributed to a Chinese state-sponsored group. [Anthropic](https://www.anthropic.com/news/disrupting-AI-espionage)
* 🛡️ **Nov 17:** The first randomized controlled trial of an AI phishing-triage agent is published. [arXiv](https://arxiv.org/abs/2511.13860)
* 🍯 **Nov 28:** Cowrie, the classic SSH honeypot, gets an experimental LLM backend. [GitHub](https://github.com/cowrie/cowrie/pull/2809)

**December**
* 🌍 **Dec 3:** React2Shell (CVE-2025-55182), a CVSS 10 remote code execution in React Server Components. [React](https://react.dev/blog/2025/12/03/critical-security-vulnerability-in-react-server-components)
* 🤖 **Dec 9:** OWASP releases the Top 10 for Agentic Applications. [OWASP](https://genai.owasp.org/2025/12/09/owasp-genai-security-project-releases-top-10-risks-and-mitigations-for-agentic-ai-security/)
* 🤖 **Dec 16:** NIST publishes a preliminary draft Cyber AI Profile (IR 8596). [NIST](https://csrc.nist.gov/pubs/ir/8596/iprd)
* 🌍 **Dec 29:** A destructive attack hits Poland's energy sector (30+ wind and solar farms), though power and heat supply continue. [CERT Polska](https://cert.pl/en/posts/2026/01/incident-report-energy-sector-2025/)
